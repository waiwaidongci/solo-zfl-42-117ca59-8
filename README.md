# zfl-42 小型漆线雕工坊管理

独立静态前端应用，直接打开 `index.html` 即可使用。

已实现闭环：
- 新增作品并记录胎体、纹样、线条、贴线进度、阴干日期、金粉状态、缺陷和交付日期。
- 工序看板覆盖贴线中、待阴干、上金粉、待交付。
- 今日待阴干、缺陷作品、最近交付三类列表。
- 可更新状态、记录断线/翘线、查看作品详情。
- 支持筛选、交付排序、localStorage 持久化和 JSON 导出。

工匠排班与工时结算：
- 工匠登记：可承担工序、日工时上限、计费方式（计时/计件）与费率，费率可随时调整。
- 工序排班：按作品工序安排日期、开始时段、预计工时与工匠；同一人同日超额、时段重叠、技能不匹配均不能派工。
- 工序流转：待安排 → 已排班 → 进行中 → 待验收 → 已完成，禁止越序、重复完成；仅「已完成」可结算（禁止未验收结算）；待验收可填原因退回返工。
- 暂停/恢复：暂停后恢复保留原排班与累计工时，暂停中不可流转。
- 改期：改期冲突时整单撤回并在撤回记录中说明原因；改期成功保持排班时锁定的费率。
- 结算：计件与计时不能混用，需分开生成结算单；费率按排班时点快照固定，后续调价不影响已排班工序。
- 结算单锁定后不可改；冲正必须填写原因，冲正记录引用原结算单号并释放工序回待结算。
- 全部数据存于 localStorage（zfl42Craftsmen / zfl42Processes / zfl42Settlements / zfl42Reversals / zfl42Withdrawals），刷新后结果一致。
- 多标签并发安全：所有共享状态变更经 Web Locks 互斥事务，锁内重读最新数据再校验、写入，不用标签内旧快照覆盖整份记录；两个标签同时提交冲突排班时只有一个成功，另一个得到冲突提示；其他标签通过 storage 事件实时同步。
